# 法拍房专项手册 Legal Auction Playbook

> 法拍房不是"打折的二手房"，是**另一种风险资产**。
> 便宜的代价是：信息不对称 + 权利瑕疵 + 交付不确定。
> 本手册的目标是让用户**看清真实成本与真实风险**，而不是帮用户"捡漏"。

---

## 1. 必须向用户讲清的三条硬事实

每次法拍输出都必须包含，不可省略：

1. **法院只对权利现状负责，通常不负责清场交付。**
   "拍到了"不等于"住得进去"。腾退是买受人的事，遇上拒不腾退的被执行人，可能要另案起诉。

2. **税费承担看公告，常见"一切税费由买受人承担"。**
   若原房主是企业、或房屋性质是"赠予/继承取得"，土地增值税可能高达差额的 30%–60%，
   这一项就可能吃掉全部折价空间。

3. **限购同样适用。**
   绝大多数限购城市的法拍房**同样受限购约束**（部分城市另有细则）。
   竞拍前必须先确认购房资格，否则悔拍没收保证金。

## 2. 真实成本测算（必须输出，不能只报起拍价）

```
综合成本 = 成交价
        + 税费（契税 / 增值税及附加 / 土地增值税 / 个税，按公告承担方）
        + 欠费（物业费 / 水电燃气 / 供暖 / 滞纳金）
        + 清场成本（协商搬离费 / 诉讼费 / 时间成本，经验值 1–5 万）
        + 资金成本（保证金冻结期 + 全款支付周期短，通常 7–15 天内付清）
        + 中介/尽调服务费（若委托）
```

**决策比值**：
```
性价比 = 综合成本 / 同小区同户型市场成交价
```
| 比值 | 建议 |
|------|------|
| < 0.80 | 折价明显，值得推进（前提是风险项已排查） |
| 0.80 – 0.95 | 折价一般，需风险项干净才值得 |
| > 0.95 | **不值得拍**，直接说明"没有捡漏空间" |

> 15 年经验：真正能捡漏的标的是少数，多数二拍房拍到后来会溢价。
> 我们的价值是**拦住不该拍的**，不是怂恿用户往上冲。

## 3. 风险扣分表

| 风险项 | 扣分 | 说明 |
|--------|------|------|
| 法院明确**不负责清场交付** | -15 | 最高频风险 |
| 存在**长期租约**（尤其 10 年以上、一次性付租） | -15 | "买卖不破租赁"，可能长期收不到房 |
| 税费**全部由买受人承担** | -10 | 需重点测算土地增值税 |
| **产权不清**（共有、继承未办、预告登记、多轮查封） | -20 | 一票否决级 |
| 房屋**有占用/有人居住**且性质不明 | -10 | |
| 土地性质为**划拨/集体** | -15 | 需补缴出让金，且可能过不了户 |
| 房屋**未腾空、未知室内状况** | -5 | 无法看样的要额外谨慎 |
| 被执行人为**企业** | -8 | 土地增值税风险高 |
| **多次流拍后的变卖** | -5 | 通常意味着前面的人发现了问题 |
| 公告信息**过于简略**（无评估明细、无附件） | -8 | |

**风险分**（越低越危险）：`risk_score = 100 + Σ扣分`，并给出文字定级：
- ≥ 85：`风险较低`
- 70–84：`风险中等，需尽调`
- 55–69：`风险较高，建议专业尽调`
- < 55：`高风险，不建议非专业人士参与`

## 4. 尽调清单（Checklist）

报告里以可勾选清单输出，逐项标注 `已确认 / 未获取 / 需线下核实`。

### A. 权属与法律状态
- [ ] 不动产登记信息：权利人、共有情况、面积、用途、土地使用权类型与期限
- [ ] 查封情况：首封/轮候、查封法院、是否为本案处置法院
- [ ] 抵押情况：抵押权人、余额、是否涤除
- [ ] 是否已办理产权证（无证的需确认能否办理）
- [ ] 土地性质：出让 / 划拨 / 集体（划拨需补缴出让金）
- [ ] 房屋性质：住宅 / 公寓 / 商住（直接影响税费、落户、学区）
- [ ] 有无预告登记、异议登记

### B. 占用与交付
- [ ] 是否有人居住、居住人身份（被执行人 / 承租人 / 案外人）
- [ ] 有无租赁合同、租期、是否已一次性付租
- [ ] 法院是否负责交付/清场（公告原文表述）
- [ ] 房屋是否腾空，能否看样
- [ ] 有无老人、病人等特殊占用情形（清场难度陡增）

### C. 税费与欠费
- [ ] 取得方式：买卖 / 赠予 / 继承（决定个税与土增税）
- [ ] 是否满五唯一 / 满二（决定增值税与个税）
- [ ] 被执行人类型：个人 / 企业（企业涉及土增税）
- [ ] 税费承担方公告原文
- [ ] 物业费、水电燃气、供暖欠费金额
- [ ] 有无未缴契税、维修基金

### D. 房屋本身
- [ ] 户型图与实测面积（评估报告中）
- [ ] 房龄、楼层、朝向、装修状况
- [ ] 是否凶宅、是否发生过事故（公告通常不写，需线下打听）
- [ ] 学籍/学位是否被占用（**关键**，多数城市学位锁定多年）
- [ ] 户口是否被占用、能否迁出
- [ ] 是否有违建、是否被城管立案

### E. 程序与资金
- [ ] 保证金金额与冻结/退还规则
- [ ] 尾款支付期限（通常 7–15 天，**必须提前备好全款**）
- [ ] 是否可贷款（多数需全款，少数城市有"法拍贷"，要提前批贷）
- [ ] 延时竞价规则
- [ ] 悔拍后果（保证金不退 + 补差）

## 5. 各平台法拍数据特点

| 平台 | 优势 | 短板 |
|------|------|------|
| 阿里法拍 | 标的最全、附件（评估报告/照片）质量最高、出价记录完整 | 风控最强，需登录态；延时竞价导致"当前价"≠成交价 |
| 公拍网 | 区域补充（偏上海），详情页服务端渲染、字段规整 | 覆盖面有限 |
| 重庆联交所 / 中拍平台 / 北交所 | 区域或品类补充 | 多为 SPA/反爬，需浏览器渲染或人工取证 |
| 公拍网 / 中拍平台 | 区域补充（公拍网偏上海） | 覆盖面有限 |

**跨平台交叉是刚需**：同一标的常在多平台同步挂拍，不同平台的附件完整度差异极大。
**必须做跨平台去重**（标的名称 + 法院 + 案号 + 面积），并合并各自的附件。

## 6. 户型图获取（法拍特有问题）

法拍详情页**通常没有户型图**。正确路径：

1. 下载《拍卖公告》《评估报告》《不动产登记信息》附件（PDF 或长图）
   —— **户型图与房本信息几乎都在评估报告里**
2. 附件在详情页的"公告/附件"区域，常见为 PDF 链接或图片
3. 下载到 `assets/` 并在报告中标注附件类型与页码提示
4. 确实找不到时，报告里写：
   > 户型图：未获取（法拍源通常不提供）。
   > 建议：① 下载评估报告附件查看；② 联系法院申请阅卷；③ 报名后按公告时间实地看样。

**绝不用模型生成"示意户型图"** —— 那是编造，违反 R8 红线。

## 8. 一句话提醒（每次收尾必说）

> 法拍房的核心风险不在价格，在**交付与税费**。
> 报告中的成本测算为估算，实际以法院公告与税务核定为准；
> 涉及大额标的建议委托专业尽调机构与律师，**本技能产出不构成投资建议**。
